Ejercicio 1: Buscador en Tiempo Real con Filter (DOM + Inputs)
Objetivo: Crear una lista de elementos en HTML (ej. de usuarios o productos) y un campo <input type="text">. A medida que la persona escribe, la lista debe filtrarse en tiempo real mostrando solo los ítems que coincidan con el texto introducido.

Conceptos a ejercitar: Evento input, .filter() o .includes(), y manipulación de element.style.display o innerHTML.

Ejercicio 2: Selector de Tema Oscuro / Claro con LocalStorage (Persistencia)
Objetivo: Crear un botón que alterne el modo claro y oscuro de la página (cambiando una clase CSS en el body). Lo clave es que al recargar la página o cerrar el navegador, la preferencia del usuario se mantenga guardada.

Conceptos a ejercitar: Evento click, classList.toggle(), localStorage.setItem() y localStorage.getItem().

Ejercicio 3: Componente de Acordeón / Preguntas Frecuentes (UI/UX)
Objetivo: Maquetar una lista de 3 preguntas frecuentes. Al hacer clic sobre el título de una pregunta, debe desplegarse su respuesta. Si el usuario hace clic en otra pregunta, la respuesta anterior se debe cerrar automáticamente (solo una abierta a la vez).

Conceptos a ejercitar: Delegación de eventos o iteración de nodos con querySelectorAll, clases activas CSS y control de visibilidad.

Ejercicio 4: Temporizador / Cronómetro con Alerta Visual (Async / Timers)
Objetivo: Crear un temporizador donde el usuario ingrese una cantidad de segundos y presione "Iniciar". La pantalla debe ir mostrando la cuenta regresiva segundo a segundo. Cuando llegue a 0, el fondo de la pantalla debe parpadear en rojo o mostrar un mensaje de alerta.

Conceptos a ejercitar: setInterval, clearInterval, manejo de estado y actualización dinámica del DOM.

Ejercicio 5: Drag and Drop de Tareas Simplificado (Kanban Basico)
Objetivo: Crear dos columnas (ej: "Pendientes" y "Completadas"). Cada tarea debe tener un botón o un checkbox que al presionarlo mueva dinámicamente el elemento HTML completo de una columna a la otra.

Conceptos a ejercitar: Eventos en botones dinámicos, appendChild() o remove(), y reorganización del DOM.
